# ci-cd-final-project

## Project Overview

This project demonstrates a Continuous Integration and Continuous Delivery (CI/CD) pipeline using GitHub Actions and OpenShift Pipelines (Tekton).

## Technologies

- GitHub Actions
- Python
- Flake8
- Nose unit testing
- Tekton
- OpenShift

## Project Objectives

- Automate code linting.
- Run unit tests.
- Build the application image.
- Deploy the application using OpenShift Pipelines.
